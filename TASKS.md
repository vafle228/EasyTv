# Задачи EasyTv

Источник работы для агентов вместе с прямыми запросами пользователя. План ниже не означает, что функции уже реализованы или что их нужно выполнять все подряд. Перед началом выбранной задачи уточнить её границы, записать критерии готовности и отметить статус; после завершения добавить ссылку на PR и результат проверок.

Статусы: запланировано → в работе → на ревью → завершено (после слияния).

| ID | Задача | Статус | Границы / что уточнить |
| --- | --- | --- | --- |
| AI-01 | Улучшение видео через RelayVSR | На ревью | Общий тумблер и режимы «В потоке» / «Готовый файл», отдельный GPU-контейнер, веса на D:/RelayVsrModel; предварительная обработка очереди, сохранение звука и оригиналов. Модель остаётся в памяти GPU между заданиями, включая отмену и смену приоритета; история кадров создаётся заново. Прошли 81 тест в Docker/Linux, 9 тестов worker на Windows и сборка фронтенда; реальный GPU-прогон локального и HTTP-видео, ранняя выдача потока, Range и браузерный просмотр 1080p. На RTX 5060 Ti повторный прогон 5 секунд 270p → 1080p занял 18,5 секунды против 101 секунды холодного запуска; реальный ТВ не проверялся. [PR #8](https://github.com/vafle228/EasyTv/pull/8) |
| UX-01 | Улучшить основной сценарий с телефона | Запланировано | Поиск → сохранение → запуск на ТВ; выбрать конкретное неудобство перед реализацией |
| UX-02 | Перемотка видео на ТВ | Завершено | На странице ТВ и в пульте работают кнопки ±10 секунд и выбор позиции на шкале. API проверяет состояние ТВ и границы позиции. Прошли 36 тестов бэкенда, сборка фронтенда и проверка управления в Chrome с тестовым ТВ. [PR #4](https://github.com/vafle228/EasyTv/pull/4) |
| UX-03 | Очередь просмотра на ТВ | На ревью | Отдельная очередь на каждом ТВ. Готовые видео и серии из каталога добавляются в конец. Пункты можно удалить, а следующий запустить с пульта или автоматически после завершения видео. Очередь переживает перезапуск сервера. Прошли 60 тестов бэкенда и сборка фронтенда. Автопереход проверен с имитацией ТВ. [PR #7](https://github.com/vafle228/EasyTv/pull/7) |
| SRC-01 | Добавлять полезные источники контента | Запланировано | Конкретный источник и критерии выбирать с пользователем; интеграция через порты |
| SRC-04 | Добавлять видео по прямой ссылке | Завершено | Поле «Добавить» принимает прямые HTTP(S)-ссылки, включая редиректы и адреса без расширения. Готовое видео появляется в библиотеке и отдаётся с правильным MIME-типом. Прошёл 51 тест бэкенда, сборка фронтенда успешна. [PR #5](https://github.com/vafle228/EasyTv/pull/5) |
| USER-01 | Домашние пользователи и история | Запланировано | Без обязательных паролей; способ идентификации не выбран. Просмотренное, «хочу посмотреть», продолжение с позиции |
| SRC-02 | Торренты | Запланировано | Подключить реальный бэкенд вместо демо; сначала определить сценарий |
| SRC-03 | Прямой эфир | Запланировано | Источники и управление пока не определены |
| OPS-01 | CI в GitHub | Запланировано | Автоматические проверки PR; агент дожидается результата и исправляет падения |
| OPS-02 | Автоматическая доставка на домашний сервер | Запланировано | Пока нет сервера; среда и правила обновления требуют решения |

Технические задачи добавляются сюда отдельно при их постановке. Приоритеты списка не задают порядок исполнения. Зависимости предварительно согласовываются согласно `AGENTS.md`.
