# EasyTv

Локальный сайт, который находит телевизоры в домашней сети и запускает на них видео: файлы с компьютера, ролики с YouTube или аниме с animego. Работает с любым телевизором, который умеет DLNA (Samsung, LG, Sony, Philips, Android TV).

## Запуск

Нужен Docker Desktop. В Git Bash из папки проекта:

```bash
./run.sh
```

Скрипт сам определит IP компьютера в сети, соберёт образ, поднимет контейнер и откроет http://localhost:8080. С телефона сайт открывается по адресу, который скрипт напечатает в конце.

| Команда | Что делает |
|---|---|
| `./run.sh` | собрать и запустить |
| `./run.sh down` | остановить |
| `./run.sh logs` | логи сервера |
| `./run.sh discover` | показать телевизоры, которые видно с этого компьютера, и их адреса |
| `./run.sh rebuild` | пересобрать без кэша, в том числе обновить yt-dlp (если YouTube перестал скачиваться) |
| `./run.sh test` | прогнать тесты |
| `./run.sh native` | запустить без Docker (Python 3.11+, Node.js, желательно ffmpeg) |

Настройки лежат в `.env`, он создаётся из `.env.example` при первом запуске.

## Как пользоваться

1. На главной видны найденные телевизоры. Экран светится, если телевизор в сети. Поиск идёт каждые 15 секунд, кнопка «Искать сейчас» запускает его сразу. Если телевизор не нашёлся сам, впишите его IP в поле «Добавить по адресу».
2. Откройте телевизор. Добавьте видео: выберите файл на компьютере (или перетащите его) либо вставьте ссылку на YouTube и нажмите «Скачать».
3. Когда видео готово, нажмите «Показать». На экране телевизора на странице видно, что играет, сколько прошло, есть пауза и стоп.

4. **Каталоги** — поиск по animego. На странице тайтла выберите серию и озвучку, нажмите «Смотреть» и решите, где показать: в этом браузере или на телевизоре. Видео идёт через сервер без скачивания; стрелка рядом с серией скачивает её в библиотеку. «Сохранить в кинотеатр» кладёт тайтл в раздел **Кинотеатр**, там же видно, на какой серии вы остановились.

Библиотека видео общая для всех телевизоров. Она и список найденных телевизоров хранятся в `data/` и переживают перезапуск. Тема (светлая, тёмная или как в системе) переключается в правом верхнем углу и запоминается в браузере.

## Как это устроено

- **Поиск.** Обычный способ — SSDP (multicast), но из Docker он в домашнюю сеть не выходит. Поэтому телевизоры находятся тремя путями:
  1. `run.sh` перед запуском ищет телевизоры с самого компьютера (там multicast работает) и передаёт в контейнер адреса их описаний (`EASYTV_TV_LOCATIONS`);
  2. сервер сам проверяет адреса из `EASYTV_TV_HOSTS` и из поля «Добавить по адресу»: по IP он перебирает типичные адреса описания DLNA (у Samsung это порты 7676, 9197, 52235);
  3. каждый найденный телевизор запоминается, и дальше сервер просто читает его описание по HTTP, чтобы понять, в сети ли он. HTTP через Docker проходит без проблем.
- **Воспроизведение** — UPnP AVTransport: телевизору отправляется ссылка на видео (`SetAVTransportURI` + `Play`), и он сам скачивает его с сервера по HTTP с поддержкой Range (перемотка работает).
- **animego** — адаптер `infrastructure/animego/` за портом `CatalogSource`: поиск, карточка (JSON-LD), серии и озвучки из AJAX-эндпоинтов сайта, прямые MP4 из плееров CVH (до 1080p) и Kodik (720p). Aniboom отдаёт только HLS, его без ffmpeg пока не показать. Ссылки временные и привязаны к IP, поэтому сервер получает свежую прямо перед просмотром и сам проксирует видео через `/stream/...` с Range и DLNA-заголовками. Если сайт поменяет вёрстку, на экране будет понятная ошибка, а тесты на сохранённых страницах (`backend/tests/fixtures/animego/`) покажут, что именно сломалось.
- **YouTube** — ролик скачивается через [yt-dlp](https://github.com/yt-dlp/yt-dlp) (поддерживаемый форк youtube-dl с тем же API; оригинальный youtube-dl с YouTube сейчас почти не работает) в H.264 + AAC до 1080p, затем показывается как обычный файл.

```
backend/easytv/
  core/            предметная область: модели, порты (интерфейсы), сценарии
    models.py        Tv, Video, PlaybackStatus…
    ports.py         TvDiscovery, TvController, VideoDownloader, VideoStorage, репозитории
    services.py      TvService, VideoLibrary, PlaybackService
    catalog.py       CatalogService (сайты), CinemaService (сохранённые тайтлы)
  infrastructure/  реализации портов
    ssdp.py          SSDP-поиск (multicast + unicast)
    upnp.py          описание устройства и управление через AVTransport (SOAP)
    ytdlp.py         загрузка с YouTube
    animego/         каталог animego: парсеры страниц и плееров CVH, Kodik, Aniboom
    fetch.py         скачивание прямых ссылок (серии с сайтов)
    storage.py, repositories.py, system.py
  api/             HTTP: FastAPI-роуты, DTO, раздача видео телевизорам, хостинг SPA
  container.py     сборка зависимостей (composition root)
  config.py        настройки из переменных окружения
backend/tests/     сценарные тесты через HTTP API с подменёнными сетевыми портами
frontend/          SPA на React + TypeScript (Vite)
scripts/           поиск телевизоров с компьютера для run.sh (PowerShell и Python)
```

Ядро не знает ни про FastAPI, ни про сокеты: сценарии работают только с портами, а `container.py` подставляет реальные адаптеры. Тесты подставляют фейковые телевизор и загрузчик и проверяют сценарии целиком.

## Если что-то не работает

- **Телевизоров не видно.** Запустите `./run.sh discover`: он покажет адреса описаний телевизоров, которые видно с компьютера. Любой из них можно вставить в поле «Добавить по адресу» на сайте или в `EASYTV_TV_HOSTS`. Если с компьютера телевизоров не видно, проверьте, что они включены, а сеть в Windows «Частная».
- **Хочется, чтобы поиск работал прямо из контейнера.** Поставьте `EASYTV_NETWORK=host` в `.env`: контейнер будет в сети компьютера. На Linux это работает сразу; в Docker Desktop сначала включите Settings → Resources → Network → Enable host networking (версия 4.34+; работает ли там multicast, зависит от версии Docker Desktop). Самый надёжный вариант без Docker — `./run.sh native`.
- **Телевизор не может воспроизвести видео** (ошибка или чёрный экран). Брандмауэр Windows должен пускать входящие подключения на порт 8080 (при первом запуске Windows может спросить, разрешить ли доступ). Сеть в Windows должна быть «Частной».
- **Телевизор спрашивает разрешение на подключение.** Подтвердите один раз пультом. Чтобы не спрашивал совсем, на Samsung: Настройки → Общие → Диспетчер внешних устройств → Диспетчер подключения устройств → Уведомление о доступе.
- **Не скачивается с YouTube.** Обновите yt-dlp: `./run.sh rebuild`.

## Разработка

```bash
cd backend && python -m venv .venv && . .venv/bin/activate && pip install -e '.[test]'
EASYTV_DATA_DIR=../data python -m easytv      # API на :8080
python -m pytest                               # тесты

cd frontend && npm install && npm run dev      # SPA на :5173, запросы проксируются на :8080

EASYTV_ANIMEGO_URL=https://animego.me          # домен animego, если сайт переедет
```
